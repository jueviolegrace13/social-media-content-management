# Phase files

One file per phase. Progress across phases is tracked in [PLAN.md](../../PLAN.md).

Each phase file has the same sections:

- **Status:** Not started, In progress or Complete, with dates.
- **Goal:** one or two sentences.
- **Scope:** what's in and what's explicitly out.
- **Tasks:** `[ ]` / `[x]` checkboxes, grouped, with the repo each task lands in.
- **Acceptance criteria:** what must be true to mark the phase complete in PLAN.md.
- **Depends on:** earlier phases or outside steps.
- **Change log:** dated notes whenever the phase's scope or approach changes.
